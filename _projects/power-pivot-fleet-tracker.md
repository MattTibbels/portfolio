# Power Pivot Fleet Tracker

## Overview

I built a fleet visibility dashboard that combined device management exports, asset information and location mapping into a clearer reporting view.

## Problem

Device age, location and lifecycle information was spread across multiple sources, making it difficult to prioritise replacement and reallocation decisions.

## Approach

I combined data from separate sources into a structured reporting model and created a dashboard view that made device age, location and allocation easier to interpret.

## Outcome

The dashboard improved visibility of fleet condition and supported more evidence-informed planning.
